# 用户端设计风格规范

> 风格代号：**Midnight Haute · 午夜高级珠宝私享会所**  
> 适用范围：微信小程序、H5、移动端用户中心  
> 参考来源：用户提供的首页、典藏列表、购物袋、尊享会籍四张界面图  
> 生效日期：2026-08-27

---

## 1. 风格定位

用户端不是常规电商商城，也不是简单的“黑底加金色”。它应当呈现一种兼具以下特征的数字化私人珠宝会所：

- **高级珠宝沙龙感**：深色展厅、藏金细节、克制聚光、大片商品摄影。
- **私人银行终端感**：严谨网格、精确数字、清晰分隔、身份与权益可信可查。
- **博物馆典藏感**：商品被称为“藏品”，信息强调系列、材质、工艺、证书与出处。
- **私人顾问服务感**：AI 顾问、专属顾问、预约鉴赏与会籍权益贯穿关键页面。
- **高密度但不拥挤**：信息丰富，依靠字阶、细线和间距建立秩序，不依靠大量卡片套卡片。

推荐对外描述：

> 午夜高级珠宝私享会所：以曜石深蓝为展厅，以古董金为引导，以象牙白衬线字体建立殿堂感，让商品浏览、私人服务与会员身份共同构成高净值用户体验。

## 2. 不可改变的品牌骨架

后续即使为不同租户设计主题，以下体验骨架也必须保留。

### 2.1 视觉层级

1. 页面画布使用近黑冷色，不使用纯黑。
2. 品牌、页面主标题使用高对比衬线字体。
3. 金色只用于品牌、价格、选中态、主操作和高价值信息。
4. 正文与辅助信息使用冷灰色，不使用大面积纯白正文。
5. 卡片依靠一级亮度差和单像素边框分层，禁止厚重阴影。
6. 商品图片承担主要情绪表达，UI 本身保持克制。

### 2.2 页面结构

- 顶部为稳定的品牌与搜索区域。
- 中部根据场景切换为首页叙事、目录检索、交易确认或会员服务。
- 底部使用固定六入口导航，中央 AI 私享入口视觉抬升。
- 搜索、筛选、价格、规格和状态必须始终可扫描。
- 主要内容区域与底部导航之间必须预留安全距离。

### 2.3 交互气质

- 操作反馈应安静、快速、确定，不使用夸张弹跳和炫光。
- 主按钮可以实心金色；次按钮只能使用金色细边或深色表面。
- 选中态通过金色边框、浅金底或底部短线表达。
- 危险操作使用低饱和红色，仅在确认删除、失效或异常时出现。
- 页面不得出现无响应按钮、假消息数量或无法执行的咨询入口。

### 3.2 色彩比例

页面整体建议遵循：

- 70% 近黑蓝背景与表面。
- 20% 象牙白、冷灰文字与商品图片。
- 8% 边框与中性色控件。
- 2% 金色和语义色。

金色面积越少越显贵。禁止将大面积页面背景、整张普通卡片或长段正文改成金色。

### 3.3 明暗关系

- 页面画布与一级表面的亮度差控制在 6%～10%。
- 一级表面与二级表面的亮度差控制在 4%～8%。
- 普通卡片使用冷灰边框；只有会员卡、优惠券、选中筛选等重点对象使用金边。
- 阴影只用于悬浮主入口或图片卡，普通列表以细边和分割线为主。

## 4. 排版系统

### 4.1 字体角色

| 角色          | 推荐字体                                                                       | 使用场景                                |
| :------------ | :----------------------------------------------------------------------------- | :-------------------------------------- |
| Display Serif | `Cinzel`, `Cormorant Garamond`, `Didot`, `Noto Serif SC`, `Songti SC`, `serif` | 品牌、英文页面标题、VIP 等级、Hero 标题 |
| UI Sans       | `Inter`, `Plus Jakarta Sans`, `PingFang SC`, `system-ui`, `sans-serif`         | 导航、搜索、说明、按钮、列表正文        |
| Numeric Mono  | `JetBrains Mono`, `SF Mono`, `DIN Alternate`, `monospace`                      | 价格、积分、VIP 编号、证书号、规格数值  |

### 4.2 字阶建议

| 层级         | 移动端字号 | 行高 | 规则                               |
| :----------- | :--------- | :--- | :--------------------------------- |
| 品牌字标     | 20～24px   | 1.1  | 全大写，字间距 0.22em～0.32em      |
| 页面 H1      | 24～28px   | 1.25 | 中英混排，衬线体，居中或左对齐     |
| Hero H1      | 30～36px   | 1.2  | 最多两行，不允许压住主按钮         |
| 模块 H2      | 18～22px   | 1.35 | 衬线体或中文中黑                   |
| 商品标题     | 16～18px   | 1.4  | 最多两行，目录模式最多一行         |
| 正文         | 13～15px   | 1.65 | 冷灰色，避免过细字重               |
| 标签/Caption | 11～12px   | 1.4  | 单行，必要时使用等宽字体           |
| 价格         | 18～24px   | 1.2  | 等宽或 DIN，必须突出小数与单位关系 |

### 4.3 中英混排规则

- 英文系列名可使用全大写衬线体和较大字距。
- 中文标题不强制全粗，应保持字面留白。
- 英文眉题、证书号、SKU 和价格使用等宽或窄体数字。
- 不在同一行混用三种以上字体角色。
- 长英文商品名必须限制行数，并提供省略而不是挤压按钮。

## 5. 网格、间距与几何

### 5.1 页面网格

- 以 750rpx 设计稿为基准。
- 页面左右安全边距：`32rpx`～`40rpx`。
- 模块垂直间距：`40rpx`～`56rpx`。
- 卡片内部间距：`24rpx`～`32rpx`。
- 紧凑元素间距：`8rpx`、`16rpx`。
- 所有间距遵循 8pt Grid，不使用无意义的 13px、17px、29px。

### 5.2 圆角

| 元素             | 圆角                         |
| :--------------- | :--------------------------- |
| 页面大卡、Hero   | 14～16px                     |
| 商品卡、权益卡   | 12～14px                     |
| 输入框、筛选按钮 | 18～24px；仅此类控件可胶囊化 |
| 普通按钮         | 10～14px                     |
| 标签             | 4～8px                       |
| 头像、图标主入口 | 50%                          |

禁止所有容器无差别使用大胶囊圆角。卡片与控件必须有明确几何区分。

### 5.3 边框与阴影

- 普通边框：1px 冷灰蓝。
- 重点边框：1px 半透明藏金。
- 分割线：1px，横向留出 16px～24px 内缩。
- 普通卡片不使用明显投影。
- 中央 AI 入口允许柔和金色外圈，但禁止霓虹发光。

## 6. 全局用户端框架

### 6.1 顶部品牌区

顶部结构从上到下为：

1. 小程序安全区和系统状态区。
2. 门店入口、居中品牌字标、AI/消息入口。
3. 全局搜索框与 AI 私享顾问按钮。
4. 1px 金色低透明分割线。

规则：

- 品牌字标必须拥有页面顶部最高视觉权重。
- 门店按钮使用金边深底，不使用实心亮色。
- 搜索框使用二级表面与冷灰边框。
- AI 顾问使用古董金表面或金边，不能抢过品牌字标。
- 顶部区在目录、购物袋、会籍页保持结构一致，建立产品识别。

### 6.2 底部导航

默认四入口：

1. 殿堂臻品
2. 传世典藏
3. 私享袋
4. 尊享会籍

规则：

- 底部导航固定并适配安全区。
- 中央 AI 私享入口使用圆形抬升结构，是唯一允许突出导航栏轮廓的入口。
- 当前页面使用金色图标、文字和底部短线。
- 未选项使用冷灰蓝。
- 红点只展示真实未读或待处理数量。
- 导航文字始终单行，不得挤压或缩成不可读字号。

## 7. 页面模式

### 7.1 首页：品牌叙事与精选陈列

首页采用“大片 Hero + 价值背书 + 分类筛选 + 双列商品流”。

Hero 必须包含：

- 4:5 或接近横向 16:9 的高质感商品摄影。
- 深色遮罩，保证标题对比度。
- 眉题标签、主标题、简短说明。
- 一个实心金色主操作和一个金边次操作。
- 底部三项以内的品牌背书，例如原石严选、证书、特保押运。

首页筛选区：

- 一级分类使用横向滚动胶囊 Tab。
- 专业筛选使用独立边框容器，例如克拉、材质、颜色。
- 选中项使用实心金色或浅金底；未选项使用二级表面。
- 筛选变化必须真实影响商品结果。

### 7.2 典藏列表：高密度检索目录

目录页强调检索效率，不重复首页的大幅 Hero。

- 页面标题居中，英文 + 中文双语。
- 搜索框横向占满内容区。
- 一级品类和材质筛选分成两行。
- 商品使用横向列表卡：左侧图片，右侧系列、名称、卖点、标签、价格和详情按钮。
- 商品图建议 1:1；卡片高度保持一致。
- 系列名与价格使用金色，商品名使用象牙白。
- “鉴赏详情”是次级金边按钮，不使用大面积实心金。

### 7.3 私享购物袋：交易确认工作台

购物袋不是普通白底结算页，应保持会所服务语境。

- 顶部先展示全选、件数和特保押运政策。
- 商品卡包含选择框、图片、名称、规格、定制铭文、价格、数量与删除。
- 数量步进器使用紧凑矩形，不使用巨大圆形按钮。
- 优惠券作为独立可选择行，明确展示已减金额和选中状态。
- 服务承诺放在商品与结算之间，以盾牌图标和正文说明呈现。
- 结算操作区后续应固定在底部导航之上，并始终显示选中金额与件数。

### 7.4 尊享会籍：身份、价值与人工服务

会籍页由三层组成：

1. **身份层**：会员等级、VIP 编号、年度累计、积分、有效期。
2. **服务层**：专属顾问头像、状态、资质、真实联系方式和咨询操作。
3. **权益层**：编号权益清单、预约、保养、押运、定制等可兑现服务。

会员卡规则：

- 允许使用从墨绿黑/古铜到深蓝黑的低对比度材质过渡。
- 渐变只模拟金属或卡面材质，色相跨度必须小于 25°。
- 关键数字使用金色等宽字体。
- VIP 编号使用金边胶囊，但不能覆盖会员等级标题。

## 8. 核心组件规范

### 8.1 搜索框

- 高度 44～48px。
- 搜索图标放左侧，颜色为金色或冷灰。
- 占位文字使用 `--c-text-secondary`。
- 有独立 AI 搜索时，放在搜索框右侧作为同高度按钮。

### 8.2 筛选 Tab 与标签

- Tab 必须单行横向滚动，不允许折行。
- 激活 Tab：金色边框 + 香槟金低透明底。
- 专业属性标签使用直角偏小圆角，不能全部胶囊化。
- 数量、材质、证书类标签使用等宽字体更易扫描。

### 8.3 商品卡

商品卡必须至少包含：

- 真实商品图片或明确的“图片待上传”占位。
- 系列/分类眉题。
- 商品名称。
- 1～2 行真实卖点。
- 价格或“价格待询”。
- 可执行的详情入口。

禁止：

- 编造库存、证书、销量或专柜标签。
- 图片上堆叠超过两个角标。
- 在一张商品卡内再套同样阴影的小卡片。

### 8.4 按钮层级

| 层级        | 样式                       | 示例                   |
| :---------- | :------------------------- | :--------------------- |
| Primary     | 实心亮金 + 深色文字        | 探索高级珠宝、确认结算 |
| Secondary   | 深底 + 金色细边 + 金色文字 | AI 选钻、鉴赏详情      |
| Tertiary    | 无底色文字按钮             | 查看全部、清除筛选     |
| Destructive | 深底 + 低饱和红色          | 删除、取消订单         |

同一屏幕最多出现一个高权重 Primary 按钮。

### 8.5 状态与徽章

- 正常/在线/已优惠：祖母绿。
- 等待/提醒/库存紧张：琥珀金。
- 失败/删除/超时：低饱和宝石红。
- 普通状态：冷灰蓝。
- Badge 文字必须单行，红点必须来自真实状态。

## 9. 图片与图标规范

### 9.1 商品摄影

- 背景优先使用黑丝绒、深木、灰白首饰盒、低饱和暖光。
- 图片色温保持中性偏暖，避免高饱和橙黄。
- 金属高光不过曝，钻石切面保持层次。
- Hero 图片建议 4:5 或 16:10；商品列表图建议 1:1。
- 同一列表的图片必须统一裁切比例和视觉重心。

### 9.2 图标

- 使用 1.5px～2px 线性图标。
- 默认描边为冷灰蓝，激活为亮金。
- 统一端点与圆角风格，不混用填充卡通图标。
- 皇冠、钻石、盾牌、证书、礼盒等图标只在对应语义出现。
- 不用 Emoji 代替正式产品图标。

## 10. 动效与反馈

- 页面进入：120～200ms 淡入与 4～8px 轻位移。
- 卡片按压：缩放至 0.985～0.99，持续 120～160ms。
- Tab 切换：金色边框与底色 160ms 过渡。
- 底部导航：只切换颜色和短线，不做弹跳。
- 数量变化：数字轻淡入，不闪烁整张卡片。
- Skeleton 使用同色系明暗呼吸，禁止高亮扫光。
- 尊重系统“减少动态效果”设置。

---

## 11. 可访问性与移动端约束

- 正文对比度不低于 WCAG AA 4.5:1。
- 触控区域不小于 44×44px。
- 按钮、Tab、Badge 文字不折行。
- 不能只靠颜色表达选择、错误和状态，需配合图标或文字。
- 价格、数量、优惠和总额必须具有可读单位。
- 适配微信小程序顶部胶囊和底部安全区。
- 输入法弹起时不得遮挡主要操作。
- 固定导航不得覆盖列表最后一项。

## 12. 多租户主题派生规范

### 12.1 主题分层

主题系统分为三层，禁止租户直接覆盖业务组件 CSS。

1. **Foundation Tokens**：间距、圆角、字阶、交互尺寸；平台统一，不允许租户修改。
2. **Semantic Tokens**：背景、表面、文字、边框、强调色、状态色；由主题包提供。
3. **Brand Assets**：Logo、品牌名、门店名、品牌摄影和文案；由租户配置。

业务组件只能引用语义 Token，例如 `$c-bg-surface`、`$c-text-primary`，禁止直接写主题色值。

### 12.2 允许租户配置

- 品牌 Logo 与中英文名称。
- 主金属色、次金属色和强调表面色。
- Display 字体族中的合法字体。
- 商品摄影、Hero 图和品牌文案。
- 门店名称、顾问资料、会员等级名称。
- 首页模块开关与排序，但不能破坏基础信息层级。

### 12.3 禁止租户配置

- 低于可访问性标准的文字颜色。
- 超大圆角、霓虹发光、玻璃拟态和高饱和渐变。
- 修改危险、成功、告警颜色的基本语义。
- 隐藏价格单位、订单状态、证书来源等关键业务信息。
